# XScreen 0.3.32

本版重做主界面三个滑轨的尺寸与对齐，并修正两处会让布局在特定窗口尺寸下失真的缺陷。

- 滑轨轨道加粗到 10px、滑块放大到 26px，可拖动区域随之加宽；轨道高度从约 136px 增加到约 250px，低位和高位更容易分辨。
- 修正滑轨轨道相对加减按钮偏左约 9 逻辑像素的问题：按钮与滑轨统一宽度，并补偿 WinUI 竖直滑轨模板自带的内部偏移。三列实测偏差收窄到 1px 以内。
- 修正窗口最小高度与内容需求脱节的问题。此前允许把窗口缩到 680，而内容需要 900，缩小后滑轨会被压扁。
- 修正紧凑布局不可达的问题。切换阈值原先低于窗口最小高度，该分支从未生效；现在窗口高度低于 1010 时正常切换。
- 浅色主题下滑块改为深色，此前为白色，在当前值处几乎与背景融为一体。
- 次要按钮补齐悬停与按下状态，鼠标移入时不再闪出与主题无关的颜色。
- 托盘分组标题按全部可写控件判断是否可调，此前只看亮度和音量，锐度可用时仍显示“当前不可用”。
- 背景斜线装饰降低不透明度，不再与数值和滑轨争夺注意力。

保留六项手动控制、窗口记忆、深浅主题、托盘快捷调节和自定义全局快捷键。对比度只读；Adaptive Sync、画面比例、Dual Mode 继续禁用。

推荐下载 **XScreen-Setup-0.3.32.exe**，采用 electron-builder 26.15.3 + NSIS 向导，支持选择安装目录、开始菜单和可选桌面快捷方式。安装完毕不自动启动；卸载保留设置、日志和其他用户文件。另附 ZIP 便携版、逐文件清单、blockmap、latest.yml 和 SHA256SUMS.txt。

正式发布程序集通过 24 个模拟 UI 场景共 720 项检查，并完成协议、安全、交互、诊断、托盘和安装器离线检查。只启动模拟回归宿主，真实显示器读写为 0/0；未执行正式应用、安装器或卸载器。真实安装和硬件操作仍由用户自行验收。
