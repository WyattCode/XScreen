# XScreen 0.3.31（安装器修订 1）

修复覆盖升级时误报“XScreen 无法关闭”的安装器问题。应用功能与 0.3.31 相同，安装器文件版本为 **0.3.31.1**。

旧卸载器在静默启动时过早校验尚未初始化的安装模式，导致升级失败。新安装器不再调用有问题的旧卸载器，而是验证当前用户与安装目录后，只清理已知旧版本的产品文件。支持从 0.3.29、0.3.30 和 0.3.31 升级，保留偏好、日志及其他非产品文件，不强制结束程序。

请关闭旧 Setup 窗口，使用本页的 **XScreen-Setup-0.3.31.exe** 手动重新安装。安装结束不会自动启动。ZIP 便携版和应用程序集保持不变。

本修订通过安装器静态校验及 53 项源码行为回归，包括静默卸载初始化、同目录及换目录升级、文件占用、快捷方式和数据保留。构建和测试未执行安装器、卸载器或正式应用，未修改实际安装登记或显示器设置；实际升级由用户手动验收。

0.3.31 应用包含不挤动布局的浮动提示、固定关闭按钮、焦点返回及故障提示优先级修复，已通过 24 个模拟 UI 场景共 720 项离线检查。
