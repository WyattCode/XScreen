# XScreen 0.3.31（安装器修订 2）

安装器文件版本更新为 **0.3.31.2**，修复覆盖升级、静默卸载和数据保留中的三个问题。应用仍为 0.3.31，523 个应用文件及 ZIP 便携版均保持不变。

- 卸载器在初始化前记录原始目录，初始化后及删除前与当前安装登记核对，阻止旧目录的卸载器误删新位置的安装。
- 覆盖升级和静默卸载在文件变更前重新检查并取得应用互斥体，防止程序在检查后启动；发现占用或权限异常时停止，不强制结束程序。
- 移除旧的 `--delete-app-data` 删除分支，普通和静默卸载均保留偏好、日志及其他用户文件。

保留修订1的升级修复：支持从 0.3.29、0.3.30 和 0.3.31 升级，验证当前用户和安装目录后，仅清理已知产品文件，不调用已安装的旧卸载器。

请使用本页的 **XScreen-Setup-0.3.31.exe** 手动安装。安装结束不会自动启动。校验文件 **SHA256SUMS.txt** 覆盖安装包、blockmap、latest.yml、便携包及文件清单，文件名与本页下载项一致。现有应用未增加自动更新功能。

通过 **554 项静态检查、64 项源码行为回归**，包含三个缺陷的离线复现及修复验证。构建使用静态提取方式取得卸载器；本轮未执行安装器、卸载器或正式应用，未修改实际安装登记或显示器设置。实际安装、卸载、系统 Shell 和锁竞争行为仍由用户手动验收。安装器未代码签名。

已经复制到其他位置的旧卸载器不会因本次发布而自动修复，请使用当前安装目录的卸载入口。
