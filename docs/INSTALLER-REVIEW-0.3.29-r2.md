# 0.3.29 安装器第二轮离线审查

范围：electron-builder 26.15.3 + NSIS 安装器，当前用户安装、目录选择、快捷方式、覆盖升级、卸载。应用和 Core 字节不变。安装器文件版本升级至 0.3.29.2，应用仍为 0.3.29。

## 修复

1. 安装目录没有独立的归属/重解析点检查。新增本地专用目录校验，拒绝系统目录和未登记的非空目录；静默 `/D` 同样验证。跨目录升级也验证旧目录，防止旧卸载器沿链接删除其他位置的文件。
2. 桌面复选框每次启动固定为关闭。现在按旧入口实际目标恢复选择；升级重建时指向新目录，用户删除过的桌面入口继续保持关闭。
3. 卸载按名称删除桌面快捷方式，会误删其他目标的同名入口。改为读目标后再删除，开始菜单也采用同一归属逻辑；升级前检查冲突，尤其拦截旧卸载器会盲删的同名桌面入口。
4. 清单遗漏 `uninstallerIcon.ico`，且产品文件删除失败仍可能继续移除登记。补齐图标清理，删除失败立即停止并保留登记；没有声称自动回滚已删除的文件。
5. 仅 `runAfterFinish: false` 无法拦截模板的 `--force-run /S` 启动分支。覆盖 StartApp 宏，安装器不会自动启动控制应用。
6. “当前用户”配置在管理员运行时仍可能显示所有用户选项。固定当前用户，拒绝 `/allusers`；加上与应用最低目标一致的 Windows build 19041 检查。
7. 原构建默认执行临时 NSIS 生成器以产生卸载器。改用内置静态读取器，禁用执行回退，并保存卸载器二进制证据和源码哈希。

## 离线验证

执行 `Test-XScreenInstallerBehavior.py`，实际解释源码中的宏、条件、循环和卸载指令，操作系统调用使用虚拟边界；包括常规安装路径、中文/空格、目录冲突、链接目录、旧目录升级、快捷方式选择与冲突、创建失败、占用删除失败、数据保留、安装登记不一致等场景。完整性脚本校验最终 Setup、静态提取的卸载器、blockmap、更新元数据及521个原生文件。最终统计与哈希见相邻的机器报告。

没有启动任何生成的 EXE，没有真实安装或卸载，没有操作实际快捷方式、用户注册表或显示器。Windows Shell/COM、真实权限、UAC、向导交互和实际覆盖升级不在离线验证的证明范围内。本地旧安装包已归档保留；本轮没有向 GitHub 发布或替换远端资产。
