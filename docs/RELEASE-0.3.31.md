# XScreen 0.3.31

本版将全局提示改成右下角浮动卡片，提示出现或关闭时不再挤动下面的控制器。

- 信息、成功、告警和错误提示统一浮动显示；支持关闭，长文字在卡片内部滚动。
- 深浅主题下使用不透明底色，避免下方文字透出；底部工具栏与刷新入口保持可用。
- 固定关闭按钮，修复长消息滚动后按钮消失和正文重叠。
- 键盘关闭后返回可用的刷新入口；刷新禁用时返回外观选项。焦点在卡片内时可按 Escape 关闭。
- 次要告警不会覆盖尚未关闭的硬件故障原因和恢复说明。关闭提示不会解除故障暂停、自动重试或重发设置。

保留六项手动控制、窗口记忆、深浅主题、托盘快捷调节和自定义全局快捷键。对比度只读；Adaptive Sync、画面比例、Dual Mode 继续禁用。

推荐下载 **XScreen-Setup-0.3.31.exe**，采用 electron-builder 26.15.3 + NSIS 向导，支持选择安装目录、开始菜单和可选桌面快捷方式。安装完毕不自动启动；卸载保留设置、日志和其他用户文件。另附 ZIP 便携版、逐文件清单、blockmap、latest.yml 和 SHA256SUMS.txt。

正式发布程序集通过 24 个模拟 UI 场景共 720 项检查，并完成协议、安全、交互、诊断、托盘和安装器离线检查。只启动模拟回归宿主，真实显示器读写为 0/0；未执行正式应用、安装器或卸载器。真实安装和硬件操作仍由用户自行验收。
