# XScreen 0.3.29

本版复核0.3.28全局快捷键，修复三个离线复现的问题：

1. 数字编辑框打开后隐藏主窗口，快捷键会被残留编辑状态挡住。现在隐藏时丢弃该数值输入草稿，再执行用户的快捷键调节；前台编辑和拖动仍受保护。
2. 显示器刷新成功后，未解决的全局快捷键冲突提示被错误清除。现在保留注册错误；修复冲突并成功注册后才清除。
3. 快捷键偏好路径是目录或不可访问时，被误认为首次启动，可能启用默认组合。现在仅文件真正不存在时使用默认值，异常配置关闭快捷键。

补测系统实际注册冲突、注销后由另一窗口接管、反复注册/注销、隐藏编辑框、50轮交替按键，以及写入中退出。退出首先注销全部快捷键，完成已开始的一次验证，丢弃尚未发送的目标和迟到消息。

全部验证使用假设备。不会因构建、测试或打包自动改动显示器设置。本版未执行真实快捷键调节验收。

保留六项手动控制、托盘、主题、窗口记忆和六项确认重置；对比度只读，Adaptive Sync、画面比例、Dual Mode继续禁止。

验证结果：23场景428项UI检查、187项协议检查、25项交互状态检查、23项诊断检查，以及Acceptance和19项OfflineSafety回归全部通过，真实显示器读写0/0。发布包提供SHA256与逐文件清单。
