# XScreen 0.3.30

本版修复托盘提示与图标质量，并完成托盘生命周期的第二轮审查。

- 悬停提示显示 `XScreen`，补齐版本4托盘所需的标准提示标志。
- 使用13档独立绘制的托盘图标，移除外圈留白，按任务栏 DPI 选择尺寸并响应显示设置变化。
- 首次添加失败、Explorer 恢复、重复通知以及 DPI 更新丢失登记时能够恢复；恢复只调用 Shell 接口，不刷新或写入显示器。
- 图标文件临时不可读时优先重用原图，注册/修改/删除或日志失败时仍清理资源。退出会停止恢复，迟到通知不能重新添加图标。

应用保留六项手动控制、窗口记忆、主题、托盘快捷调节及自定义全局快捷键。对比度只读；Adaptive Sync、画面比例与 Dual Mode 继续禁用。

推荐安装包：**XScreen-Setup-0.3.30.exe**，使用 electron-builder 26.15.3 + NSIS，支持当前用户安装、选择安装目录、开始菜单和可选桌面快捷方式。安装完毕不自动启动，卸载保留设置、日志和其他用户文件。另提供 ZIP 便携版；两者应用载荷一致，配套逐文件清单、blockmap、latest.yml 与 SHA256SUMS.txt。

本版通过使用假设备的离线回归、Windows 本地图标解码及安装器静态验证后发布。构建静态提取卸载器，不执行安装器、卸载器或正式应用，不自动改动显示器设置。真实系统托盘观感、跨 DPI 效果与安装升级仍需用户手动验收。

验证结果：23个UI场景共428项、139项托盘检查、187项协议检查、25项交互检查、23项诊断检查、19项安全检查和Acceptance全部通过，真实显示器读写0/0。托盘资源已由Windows原生接口逐档解码；真实悬停和安装操作未自动执行。
